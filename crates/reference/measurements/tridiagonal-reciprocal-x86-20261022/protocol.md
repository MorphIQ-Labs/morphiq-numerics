## Reciprocal-pivot experiment — protocol frozen before timing

Owner authorized a measured prototype following #220, kept on a separate experimental branch based on `83c7b06808baef7a44ef5c1bb8b8eed8de6fe6d2`. No published `fast::linalg` API is added. The unpublished reference harness reuses the original factorization and computes one reciprocal per pivot. Nonfinite/zero reciprocals use direct division; successful candidates still need the existing certificate and the consumer's error budget. Result bits and range refusals can differ from the current solver.

Compare unchanged division solves and reciprocal solves with the same native binary/compiler features, plus pinned reference LAPACK 3.12.1 DGTTRS as a different-contract diagnostic. LAPACK's RHS copy/Fortran interface are included and stated; no comparable-guarantee parity claim follows.

- Synthetic orders 1, 17, 401, 4096; ordinary, mixed-sign and near-dominance matrices; 1, 8 and 64 RHSs. One RHS uses the public scalar baseline; multiple RHSs use its SIMD batch API. Interleaved input construction is outside timing.
- Separate solve-only, factor-plus-RHS group, factor/reciprocal setup, and solve-plus-certificate cells. Group cells reuse admitted matrices; admission is excluded equally. Certified batch cells include gathering columns into preallocated buffers for the per-vector certificate, equally for both methods.
- LAPACK diagnostic cells: orders 17, 401, 4096, the same three matrix kinds, one RHS; exact coefficient/RHS inputs match the existing pinned harness.
- Calibrate to 10 ms per method, warm up ABBA, then retain 21 ABBA rounds. Pin one CPU; record toolchain/features, CPU/ISA, OS, governor/frequency/load, binary/source hashes and all samples. Do not change host policy. Allocation and numerical qualification stay outside timed loops, except explicitly timed certificate work.
- Retain every attempt. Relative IQR >10% rejects a timing cell. Include a paired copy-control cell for each (order, kind, RHS-count); control drift >5% or relative IQR >10% invalidates associated cells. Repeat unstable attempts once after reviewing contention. A measured gain requires the paired ratio interval below 1 on a stable named cell; no universal speedup or native ARM claim. Host serial correlation limits the order-statistic interval interpretation.
- Independently certify fixture candidates using the existing exact-rational systems; record changed bits, fallback pivots and certificate bounds. Check scalar/SIMD equivalence within the prototype, range witnesses, signed zeros, dimension overflow and nonfinite-input behavior. Existing proofs certify arbitrary finite candidates; they do not establish a universal forward-error budget or production readiness for this experimental recurrence.

Native performance ownership remains #152 under #149. Missing/unstable evidence stays open. The decision after this experiment is whether to pursue a separately specified API, not automatic adoption into #220.
